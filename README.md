# Sistema Solar 3D 🌌

Una impresionante simulación del sistema solar en 3D construida principalmente con **CSS3** y **HTML5**. Este proyecto demuestra el poder de las hojas de estilo modernas para crear entornos tridimensionales interactivos en el navegador.

## 🌟 Características

- **Vista 3D Inmersiva**: Navegación y visualización tridimensional de los planetas y sus órbitas.
- **Animaciones Orbitales**: Movimientos precisos y fluidos para cada planeta, desde Mercurio hasta Neptuno.
- **Efectos Visuales**: Sombras dinámicas y efectos de iluminación simulados con CSS.
- **Sin Dependencias Pesadas**: Funciona nativamente en navegadores modernos, apoyado por `prefixfree` para compatibilidad.
- **Mensaje Especial**: Incluye una dedicatoria personalizada para el año 2026.

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica.
- **CSS3**: Transformaciones 3D (`transform-style: preserve-3d`), animaciones (`@keyframes`), y diseño visual.
- **JavaScript**: Gestión de clases para controlar la vista inicial y el zoom.

## 🚀 Cómo Ver el Proyecto

1. **Clona el repositorio** (o descarga el ZIP):
   ```bash
   git clone <tu-url-del-repositorio>
   ```
2. **Abre el archivo**:
   Navega a la carpeta del proyecto y abre `index.html` en tu navegador web favorito (Chrome, Firefox, Edge, Safari).

## 📂 Estructura de Archivos

```
.
├── css/
│   └── styles.css      # Estilos principales y animaciones 3D
├── js/

│   └── scripts.js      # Lógica de inicialización
├── index.html          # Punto de entrada de la simulación
└── README.md           # Documentación del proyecto
```
